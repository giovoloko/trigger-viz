Toggles

Short segments from each corner instead of full edges, same read, less ink.

pseudocode
for corner in box.corners:      // 8 total
  for axis in [x, y, z]:
    drawSegment(corner, corner - axis * edgeLen * 0.16)

A 7% opacity mesh over the box so occluded volume reads at a glance.

pseudocode
fill = Mesh(box.geometry, material)
material.transparent = true
material.opacity = 0.07
scene.add(fill)

Opacity scales with distance, floored so far boxes never fully vanish.

pseudocode
d = distance(box.position, camera.position)
opacity = clamp(1 - (d - nearDist) / fadeRange, floor, 1)

Edges drawn twice, normal depth test, plus a dim pass for the occluded ones.

pseudocode
drawEdges(box, depthTest: LEQUAL, opacity: 1.0)   // visible
drawEdges(box, depthTest: GREATER, opacity: 0.2)  // ghost pass

Raycasts from screen center each frame, nearest box wins, smoothed so it doesn't snap.

pseudocode
ray = cameraRayThroughScreenCenter()
hit = raycast(ray, pickMeshes)
target = hit ? hit.box : nearestByViewAngle(pickMeshes, camera)
focus = lerp(focus, target, 0.14)

The id tag that appears above whichever box currently has focus.

pseudocode
if nametagsEnabled and focus:
  label.text = focus.id
  label.position = project(focus.worldPosition, camera)
  label.visible = true
else:
  label.visible = false

The whole category system: colors, the types panel, mute/solo, per-box hides. Off is one plain color, everything visible, no panel.

pseudocode
if typeFilteringEnabled:
  show typesPanel
  color = typeColors[box.type]
  visible = typeFilter[box.type]
else:
  hide typesPanel
  color = defaultColor
  visible = true
